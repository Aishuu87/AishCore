Aishaddon — Addon minimal

Installation:
- Copiez le dossier Aishaddon dans le dossier AddOns de WoW Retail :
  `%ProgramFiles%\World of Warcraft\_retail_\Interface\AddOns\` (ou l'emplacement équivalent sur votre PC).
- Lancez WoW et activez l'addon dans l'écran de sélection de personnage.
- Dans le jeu, utilisez `/reload` pour recharger l'interface après modification.

Fichiers:
- `Aishaddon.toc` : fichier d'en-tête pour WoW (Interface: 120000).
- `Aishaddon.lua` : code Lua principal (affiche un message au chargement).
- `Aishaddon.xml` : ressources XML (ex. frames).

Usage rapide :
- Le addon affiche un message dans le chat quand il est chargé.
- Exemple de fonction : `addonTable.Add(a,b)` retourne la somme.
